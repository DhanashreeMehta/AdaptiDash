# AdaptiDash – AI-Based Adaptive User Interface

## Run
No installation needed. Open `index.html` in Chrome, Safari, Firefox or Edge.
Optional local server: `python3 -m http.server 8000`, then visit http://localhost:8000

## Features
- An online Naive Bayes model predicts the next tool and fills a "Suggested" split menu
- Repeated missed clicks enlarge buttons and text
- Detects the OS dark-mode and reduced-motion settings and offers to apply them
- Explanations panel, opt-out toggles and a reset button

## Test it
1. Click Email → Calendar → Notes about 5 times. The suggestions will appear.
2. Click empty space 3 times. The buttons get bigger.
3. Turn on dark mode in your OS and reload. A suggestion banner appears.
